# Приём заявок в Telegram (бесплатно)

Этот воркер принимает заявки с сайта и отправляет их тебе в Telegram.
Разворачивается на Cloudflare — **карта не нужна**, лимит 100 000 заявок в день.

Если этот файл не настраивать, сайт всё равно работает: при отправке формы
у пользователя откроется Telegram с уже готовым текстом заявки.

---

## Шаг 1. Создай бота и узнай токен

1. Открой в Telegram **@BotFather**.
2. Отправь команду `/newbot` и придумай имя бота.
3. BotFather пришлёт **токен** вида `123456789:AAE...` — сохрани его.

## Шаг 2. Узнай свой chat_id

1. Напиши своему новому боту любое сообщение (например, «привет»).
2. Открой в браузере ссылку (подставь свой токен):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
3. Найди в ответе `"chat":{"id":123456789` — это и есть **chat_id**.

> Хочешь заявки в канал? Добавь бота в канал администратором и
> используй chat_id канала (обычно вида `-1001234567890`).

## Шаг 3. Разверни воркер на Cloudflare

1. Зарегистрируйся на https://dash.cloudflare.com (бесплатно).
2. Слева выбери **Workers & Pages → Create → Worker**.
3. Назови его, например, `voidrework-orders` → **Deploy**.
4. Нажми **Edit code**, удали всё и вставь код из файла
   [`telegram-worker.js`](./telegram-worker.js) → **Deploy**.
5. Открой **Settings → Variables and Secrets** и добавь две переменные
   (тип **Secret**):
   - `BOT_TOKEN` — токен из Шага 1
   - `CHAT_ID` — id из Шага 2
6. Сохрани и снова нажми **Deploy**.
7. Скопируй адрес воркера вида
   `https://voidrework-orders.твой-ник.workers.dev`.

## Шаг 4. Подключи к сайту

Открой файл `js/config.js` и вставь адрес воркера:

```js
telegramWorkerUrl: "https://voidrework-orders.твой-ник.workers.dev",
```

Сохрани и загрузи изменения на GitHub (см. `README.md` в корне проекта).

## Проверка

Открой сайт, заполни любую форму и отправь. Заявка должна прийти в Telegram
в течение пары секунд. Если не пришла — проверь переменные `BOT_TOKEN`
и `CHAT_ID` в настройках воркера.
