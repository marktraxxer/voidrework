# Voidrework — сайт плагинов и модов для Minecraft

Статический сайт: 4 страницы, корзина, 5 языков, 6 валют.
Никакого сервера для показа не нужно — подходит для бесплатного хостинга.

---

## Быстрый старт (локально)

Просто открой `index.html` двойным щелчком в браузере.

> Некоторые браузеры ограничивают работу с файлами напрямую (`file://`).
> Если что-то не работает — запусти локальный сервер в папке проекта:
> `python -m http.server 8000` и открой `http://localhost:8000`.

## Как выложить сайт бесплатно на GitHub Pages

Нужен аккаунт GitHub (бесплатный). Дальше — 4 шага.

### Шаг 1. Создай репозиторий

1. Зайди на https://github.com и нажми **New repository**.
2. Название: `voidrework` (можно любое).
3. Тип: **Public**. Нажми **Create repository**.

### Шаг 2. Загрузи файлы

Проще всего через сайт GitHub:

1. В новом репозитории нажми **uploading an existing file**.
2. Перетащи туда файлы и папки проекта:
   - `index.html`, `plugins.html`, `product.html`, `order.html`
   - папку `css`
   - папку `js`
   - папку `worker`
   - файл `.nojekyll` (если не видно — включи показ скрытых файлов)
3. Внизу нажми **Commit changes**.

> Не загружай лишние файлы (архивы, черновики). Нужны только перечисленные выше.

### Шаг 3. Включи GitHub Pages

1. В репозитории открой **Settings → Pages**.
2. В блоке **Build and deployment** выбери:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)**
3. Нажми **Save** и подожди 1–2 минуты.

### Шаг 4. Открой сайт

Адрес будет вида:

```
https://ТВОЙ-НИК.github.io/voidrework/
```

Готово — сайт доступен всем бесплатно.

## Приём заявок в Telegram

По умолчанию при отправке формы открывается Telegram с уже готовым текстом
заявки — пользователю остаётся нажать «Отправить».

Чтобы заявки приходили **автоматически**, настрой бесплатный приёмник:
см. [`worker/README.md`](./worker/README.md).

Все настройки сайта лежат в одном файле: [`js/config.js`](./js/config.js).

---

## Структура проекта

```
index.html      — главная
plugins.html    — каталог (фильтры Все / Плагины / Моды)
product.html    — страница товара (?id=1 … ?id=8)
order.html      — заказ разработки (кнопки Плагин / Мод)
css/style.css   — все стили
js/config.js    — настройки (адрес приёмника, Telegram)
js/script.js    — товары, языки, валюты, корзина, формы
worker/         — бесплатный приёмник заявок для Cloudflare
```

---

## Что можно изменить

- **Добавить товар** — массив `products` в `js/script.js` (поля `id`, `name`, `type`, `icon`, `desc`, `price`).
- **Тексты и переводы** — объект `i18n` в `js/script.js` (ru, uz, en, kz, cn).
- **Курсы валют** — `currencyRates` в `js/script.js`.
- **Ссылки на Telegram** — `js/config.js` и футер на страницах.
